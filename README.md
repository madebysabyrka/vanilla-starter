# Vanilla Starter

A clean and lightweight starter template for building modern websites with HTML, CSS and JavaScript.

## Features

- Semantic HTML
- Modern CSS
- Vanilla JavaScript
- Responsive design
- Reusable utility classes
- Organized project structure
- No frameworks

## Project structure

```
├── styles/
│   ├── base/
│   ├── components/
│   ├── layouts/
│   ├── sections/
│   └── main.css
│
├── scripts/
│   ├── utils/
│   ├── modules/
│   └── main.js
│
├── images/
├── icons/
├── fonts/
│
└── index.html
```

## Getting started

### Use as a template

Click **Use this template** on GitHub to create a new repository based on Vanilla Starter.

### Clone the repository

```bash
git clone https://github.com/Sabyrka/vanilla-starter.git
cd vanilla-starter
```
